# シナネン株式会社 顧客情報照会システム Mock

コムテック案件のシナネン株式会社向け、見積プレゼン用Mock。

- 想定: 検針・保安・営業などの現場担当者が社用スマホで顧客情報を参照する
- データ構造: 顧客（人）に複数の供給先（ヘリオスコード）がぶら下がる
- 画面: 検索 → 顧客一覧 → 供給先一覧 → 供給先明細（顧客 / 検針 / 機器 / 入金 / 売上）
- 技術: React + Vite の静的ビルド、ダミーデータのみ、参照専用
- 公開: GitHub Pages（`main` への push で GitHub Actions が自動デプロイ）

公開URL: https://codinobaggio.github.io/sinanen-customer-reference-mock/

> 本Mockはサンプルデータのみで構成され、実データ・社内URL・認証情報は一切含まない。
